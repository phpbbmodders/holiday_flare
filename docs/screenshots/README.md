# Screenshots

Real screenshots of a phpBB board index with each theme enabled (not mockups). Captured with headless Chromium against a real phpBB 3.3.18-dev + SQLite install running this extension, one theme enabled at a time.

- `christmas-theme.png` -- `enable_xmas` on: the Santa hat in the header corner, plus the smaller matching icon on the forum list.
- `valentine-theme.png` -- `enable_valentine` on: the heart icon in the header corner.

Excluded from the packaged extension archive (see `.gitattributes`'s `docs export-ignore`); these are for the repo/PR only, not shipped to end users.
